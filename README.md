# Graphite

What is Graphite?

Graphite is a multi-platform application designed to be lightweight, fast, and accessible across almost every major operating system. Whether you are using a smartphone, a desktop computer, or a specific flavor of Linux, the app is engineered to run natively on your machine without draining your system resources.

The project focuses on a clean user experience, quick deployment, and broad compatibility, allowing users to interact with the same core application interface regardless of the device they happen to have in front of them.
Supported Platforms and File Formats

To ensure anyone can use the application, Graphite is compiled into several distinct installer types tailored for specific devices:

    Android Mobile Devices: The app is bundled as a signed Android Package (.apk) optimized specifically for modern 64-bit mobile processors. This provides a clean mobile interface that bypasses common installation issues on Android smartphones.

    Linux Desktops: Graphite supports multiple Linux distributions by offering native Red Hat Package Manager (.rpm) installers for systems like Fedora, Debian packages (.deb) for systems like Ubuntu, and standalone AppImages that run on almost any Linux setup without installation.

    Windows Computers: For standard PCs, the app compiles into reliable installation packages (.exe or .msi) that integrate directly with the Windows desktop environment.

    Apple Mac Computers: The app is packaged into standard macOS disk images (.dmg) to allow simple drag-and-drop installation for Mac users.
